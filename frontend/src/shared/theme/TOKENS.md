# CV Builder tokens — sources & open questions

How the values were obtained:

- **[F] Figma.** The file is view-only for this account (no Dev Mode, no styles or variables panel), so values were read node by node from the Properties panel on the page **Design system (components)**. Frames: `Buttons`, `Input & Textarea`, `Notifications`, each with `Light` / `Dark` sub-frames. **The file has no named color, text or effect styles and no variables**, so the "Figma node" column names the layer instead.
- **[A] App theme.** The pages `1440px Desktop` / `768px Tablet` are html-to-design captures of `cv-innowise.vercel.app`; their flow links point there, and their layers have names like `Ordered List → Item → Link`. The app's MUI theme and component styles were read from its public JS bundle (`app.ed439eb0.js`, theme module `309`, theme factory `_m`). These are the values rendered on the captured Figma screens.
- **[M] MUI default.** MUI v5 defaults, computed with `createTheme()` from the [A] palette (exact numbers, not estimates). They are **not** individually checked in Figma.

## Missing / ambiguous: questions for the designer

1. **Dark background disagrees.** The Figma Dark frame is `#2E2E2E`, but the app uses `#353535` (and `#121212` paper). The tokens use `#2E2E2E`.
2. **Dark text disagrees.** Figma uses `#F5F5F7`; the app's `text.primary` is `#FFFFFF`.
3. **Secondary color disagrees.** Figma uses `#626262` (borders, Level 1); the app's `secondary.main` is `#767676` (links such as "Forgot password").
4. **Button min-width disagrees.** Figma buttons are 160 px; the app sets `minWidth: 220`.
5. **Light input disabled fill disagrees.** Figma is `#C4C4C6`; the MUI app renders transparent with `rgba(0,0,0,.26)` text.
6. **No focus-ring spec** (keyboard focus outline) for buttons, inputs or links.
7. **Not measured in Figma (visual only or not inspected):**
   - Primary Hover fill
   - Secondary and Ghost text colors
   - Dark Secondary Active and Dark Ghost Hover
   - Dark input focused border and label color
8. **Unverified Design-system frames.** These exist but were not inspected, so their values come from [A] / [M]: `Select & Multiselect`, `DatePicker`, `Avatar Uploader`, `Table`, `Table (pagination)`, `Table (empty)`, `Loader`.
9. **Notifications and skill levels only exist in a light frame.** Are the dark-theme values the same?
10. **No Figma spec for:**
    - Checkbox / selection-mode controls (tokens use [M])
    - Project Environment chips (tokens use [M])
    - Tooltip (tokens use [M])
    - Pagination
    - Modal header / actions layout (tokens use [M])
11. **No named color, text or effect styles or variables in the file.** Ask the designer to publish styles, so the next sync can use names instead of layer paths.
12. **Typography outside the measured set.** h1–h3, h5, h6, subtitle1/2, overline and table head/cell were not found as distinct Figma text styles. The values are the MUI scale the captured screens render with.
